How the engagement works

  1. 01

    Audit scope

    We discuss which sections and languages to check, any known problems and the access I will need.

  2. 02

    Website review

    I check how search engines crawl and index the site, then review page templates, internal links and Search Console data.

  3. 03

    Report

    Each finding includes affected URLs, evidence, priority and a recommended fix.

  4. 04

    Implementation support

    Where agreed, I prepare developer tasks and validate the fixes.

What you receive

Audit report

A report with verified findings and affected URLs. Each recommendation includes evidence, priority, an implementation action and acceptance criteria.

Audit boundaries

I check the page types and languages we have chosen, along with indexing, technical settings and internal links. If you provide access, I can also review analytics and server logs.

After the report

Developer tasks, a team walkthrough and implementation validation can be agreed separately.

What I need to get started

I need the website, languages, sections, known issues and change history. Search Console, analytics and staging access are scoped to the review.

Working together and pricing

An audit is a one-off project with an agreed scope and report. Developer tasks and implementation checks are scoped before work starts.
