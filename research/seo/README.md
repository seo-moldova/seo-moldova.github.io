# Семантика сайта

Собрана 17.11.2026 через Google Keyword Planner / AllMetrics. Регион Moldova, сеть Google Search; RU/RO и дополнительная EN-выборка внутри Молдовы. Помесячные данные: ноябрь 2025 — октябрь 2026.

- keyword-source.json — исходные оценки и помесячные данные без идентификаторов рекламных клиентов. Генерация идей содержит нерелевантные строки; они не являются рекомендациями.
- keyword-map.csv — 105 отобранных сочетаний запроса и языкового таргетинга, 84 с положительным объёмом. Смысловая кластеризация и основные целевые URL.

Оценки 10 приблизительны; ноль не означает невозможность обращения. Языки, синонимы и близкие варианты не суммировать. Частотность Google не равна спросу в ChatGPT. Карта — рабочая гипотеза, фактическое распределение запросов по страницам через GSC в этот объём не входит. Консультации ведут в существующий блок форматов, отдельная страница не создаётся.

Кишинёв: seo chisinau — 20, продвижение сайтов кишинев — 10 в среднем за месяц по выбранным языковым выборкам. Спрос есть, но самостоятельное содержание для новой посадочной пока не подтверждено. J07 отложен: географию закрывает главная без заявления об офисе.
